AES MixColumns (forward) — golden test vectors
==============================================================================

Target map: FIPS-197 sec. 5.1.3, one column, GF(2^8) with modulus 0x11B,
column polynomial [02 03 01 01] (circulant).  These vectors are the
normative acceptance test: a circuit that reproduces all of them under the
convention below is computing this project's MixColumns and no other.

BYTE ORDER.  A column is four bytes s0 s1 s2 s3 printed left to right, s0
first.  out[col] = XOR_k coef[k] * in[(col+k) mod 4] with coef = 02 03 01 01.

BIT INDEX CONVENTION (the one matrix.txt and every circuit file here use):

    signal index j  =  8 * byte_number + bit_number,   0 <= j <= 31
    bit_number b of a byte is the coefficient of x^b  ->  LSB-FIRST

  So input signal 0 is the LSB of byte 0; signal 7 is the MSB of byte 0;
  signal 24 is the LSB of byte 3.  Output signal r is read the same way:
  r = 8 * out_byte + out_bit.  A verifier that gets a byte-reversed or
  bit-reversed answer is in wrong_answers.md.

Each vector is given three ways: as hex bytes, as the 32-bit vector in this
index convention (hex, bit j = signal j), and as the plain list of set
signal indices.

HOW TO USE THESE

  A circuit file in this project is a list of 2-input XOR gates over 32
  input signals.  To check it against a vector: set input signal j to bit j
  of the in vector, replay the gates in order, and read output r off the
  signal whose accumulated input-mask equals row r of matrix.txt.  That
  replay is control 2 of scripts/build_golden_vectors.py, which generates
  this file: it runs every vector below through
  circuits/mixcolumns_88gates_depth5_fromscratch.json
  gate by gate, on real bit values rather than masks, and prints the
  transcript.  Re-run it yourself:

      python3 scripts/build_golden_vectors.py --check

  These vectors are a CONVENIENCE, not the proof.  Because the map is
  linear, the 32 basis vectors (unit inputs) already determine it
  completely; verify.py compares all 32 output masks at once, which is
  why it is a proof of correctness and not a sample.  The FIPS-197
  column is here so an integrator can eyeball agreement with the
  standard.

  To check a circuit file of your own, including one this repository has
  never seen:

      python3 verify.py --adhoc <your_file.json>
